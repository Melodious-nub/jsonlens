Frequently Asked Questions

Is my proprietary data sent to any remote server?

Never. 100% of formatting, minification, tree generation, and diffing runs strictly in your local browser runtime. We store zero logs and have zero server dependencies.

How does URL Sharing protect privacy?

Share links compress payloads directly into the URL fragment (#payload=...). The fragment is never transmitted over HTTP headers to servers, preserving complete end-to-end privacy.

Can JsonLens handle multi-megabyte payloads?

Yes! Monaco Editor virtualized viewports and Angular Zoneless Signals ensure silky 60 FPS performance even on massive enterprise JSON responses.
